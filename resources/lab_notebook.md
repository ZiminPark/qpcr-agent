# 실험 노트

김 연구원이 나중에 다시 보려고 적어두는 메모. 매주 반복하는 작업이라 여기 적어둔다.

## 준비할 때 늘 지키는 것

- 샘플 하나는 항상 **3칸에 나눠 담는다** (반복 측정이라 그래야 믿을 수 있음)
- 플레이트에는 RNA 변환부터 측정까지 한 번에 해주는 시약이 미리 들어 있음 (one-step RT-qPCR)
- 한 칸에서 **IL6와 GAPDH를 함께 측정**함
- GAPDH는 측정값의 흔들림을 보정하는 기준, **S01은 샘플끼리 비교할 때의 기준**
- 희석은 **농도 50, 총량 50µL**로 맞춤
- 순도 **1.8 미만이면 불합격** — 그런 샘플은 애초에 플레이트에 안 올림
- 측정 중 이상 신호는 일단 표시만 하고, **끝난 뒤 해당 샘플을 다시 검사할지 정함**

## 보고서 쓰는 법

1. 결론부터 (요약 한두 줄)
2. 표 (샘플별 결과 — S01과 비교해서 얼마나 달라졌는지)
3. 불합격 목록 — **이유까지 반드시 적을 것** (그냥 "탈락"이라고만 쓰지 말기)
4. 특이사항 — 곡선이 이상한 칸이 있으면 어느 칸인지 적을 것
