# 실험 노트

김 연구원이 나중에 다시 보려고 적어두는 메모. 매주 반복하는 작업이라 여기 적어둔다.

## 준비할 때 늘 지키는 것

- 샘플 하나는 항상 **3칸에 나눠 담는다** (반복 측정이라 그래야 믿을 수 있음)
- 비교 기준은 항상 **GAPDH** — 이거랑 비교해서 IL6가 얼마나 늘었는지 보는 거임
- 희석은 **농도 50, 총량 50µL**로 맞춤 (계산은 그냥 C1V1=C2V2)
- 순도 **1.8 미만이면 불합격** — 그런 샘플은 애초에 플레이트에 안 올림

## 보고서 쓰는 법

1. 결론부터 (요약 한두 줄)
2. 표 (샘플별 결과)
3. 불합격 목록 — **이유까지 반드시 적을 것** (그냥 "탈락"이라고만 쓰지 말기)
4. 특이사항 — 곡선이 이상한 칸이 있으면 어느 칸인지 적을 것
